# Support

## Where to get help

- **Usage questions / how-to help**  
  Open an issue: https://github.com/josephdong1000/neurodent/issues

- **Bug reports**  
  Use the bug report template:
  https://github.com/josephdong1000/neurodent/issues/new?template=02-bug-report.md

- **Feature requests**  
  Use the feature request template:
  https://github.com/josephdong1000/neurodent/issues/new?template=01-feature-request.md

- **Documentation and tutorials**  
  See: https://josephdong1000.github.io/neurodent/

## Sensitive reports

- **Security-sensitive vulnerabilities** and **private conduct concerns** should
  not be reported in public issues.
- Contact maintainers directly at:
  - dongjp@chop.edu
  - ohy2@chop.edu
